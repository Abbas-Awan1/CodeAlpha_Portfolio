# Muhammad Abbas Awan - Portfolio Website

A modern and responsive personal portfolio website built to showcase my skills, projects, education, and experience as a Frontend Web Developer.

This portfolio represents my journey in web development and highlights the projects I have created during my Frontend Development Internship at CodeAlpha.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Modern dark theme UI
- Animated hero section with typing effect
- About me section with education and skills
- Skills showcase
- Projects display with GitHub and Live Demo links
- Resume download functionality
- Contact form integrated with EmailJS
- Direct email communication
- Smooth scrolling and animations
- Social media integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- EmailJS
- GitHub Pages
